# Customization Position Images

This folder contains position images for each product category.

## Official Rules (source of truth)

Each file represents a customization position; the position name is shown in the filename and under the product.

For garments, Left/Right refer to the wearer of the garment.
Umbrella panels are numbered clockwise, starting from the top panel.

Generated illustrative models: product proportions and details may vary between views. Blue areas indicate positions, not production sizes.

## Folder Structure

```
positions/
├── adult-tops/          # T-Shirts, Polos, Hoodies, etc.
├── youth-tops/          # Youth T-Shirts
├── infants/             # Baby clothing
├── pants/               # Work Trousers, Shorts
├── headwear/            # Caps, Beanies
├── bags/                # Tote bags, Backpacks
├── towels/              # Beach towels, Hand towels
├── blankets/            # Blankets
├── mouse-mats/          # Mouse mats
├── aprons/              # Aprons
└── non-apparel/         # Awards, Coasters, etc.
```

## Image Naming Convention

Each position image should be named using kebab-case:
- `body.png`
- `back.png`
- `left-sleeve-short.png`
- `right-sleeve-long.png`
- `left-chest.png`
- etc.
