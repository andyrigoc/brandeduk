Integration Instructions

  1. Copy the #orderPopup div from order.html into home-pc.html (before closing </body>)
  2. Add CSS links in <head>: 
    <link rel="stylesheet" href="test-order-popup/order.css">
<link rel="stylesheet" href="test-order-popup/order-overlay.css">
  3. Add scripts before closing </body>: 
    <script src="https://cdnjs.cloudflare.com/ajax/libs/jquery/3.7.1/jquery.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/jquery-easing/1.4.1/jquery.easing.min.js"></script>
<script src="test-order-popup/order.js"></script>
<script src="test-order-popup/order-integration.js"></script>
  4. Product links will automatically trigger the popup instead of navigating to product-detail.html
