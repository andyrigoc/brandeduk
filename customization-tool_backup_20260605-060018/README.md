# Customization Tool (Unified Latest)

This folder now uses a unified launcher to open the latest customization flows from the main brandeduk workspace.

## Entry points

- `index.html` -> launcher to the latest pages:
  - `../customize.html`
  - `../customization.html`
  - `../customize-positions.html`
  - `../customize-detail.html`

- `legacy-editor.html` -> preserved legacy standalone editor previously in `index.html`.

## Why this setup

Recent customization changes (search bar, updated garments/T-shirt flow, and related fixes) were implemented in the main brandeduk pages, not in the old standalone customizer files.

This launcher keeps `customization-tool` aligned with the newest implementation without losing legacy access.
